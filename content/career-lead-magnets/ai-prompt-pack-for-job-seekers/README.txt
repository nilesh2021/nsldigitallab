100 ChatGPT Prompts for Job Seekers (2026)
NSL Digital Lab — free download

How to use
1. Pick a file that matches the task (resume, cover letter, interview, networking, follow-up).
2. Copy one prompt into ChatGPT (or another AI chat).
3. Replace every [BRACKET] with your details: role, company, resume text, or job description.
4. Edit the output before you send it. Never paste AI text into an application unreviewed.

Tips
- Paste the job description in the same chat so the model can match keywords.
- Ask for a shorter version if the first draft is too long.
- Keep facts honest: metrics, dates, and tools must be true to your experience.
- This pack is for job search only. For general marketing prompts, use NSL Digital Lab’s ChatGPT Prompt Pack.
