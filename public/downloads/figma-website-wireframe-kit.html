Figma Website Wireframe Kit

Recreate these frames in Figma at 1440 × 1024 (desktop) and 390 × 844 (mobile). Use this page as the page inventory and layout starter.

How to use in Figma

1. Frames

Create Desktop / Tablet / Mobile pages. Name frames Home, About, Services, Blog, Pricing, Contact.

2. Layout grid

Desktop: 12 columns, 24px gutter, 80px margin. Mobile: 4 columns, 16px gutter, 20px margin.

3. Components

Start with Nav, Footer, Button, Card, Form field, and Section heading. Reuse them on every page.

Page inventory

  • Home Nav, hero, 3 service cards, proof/logos, featured work, CTA, footer.
  • About Story, team or process, values, CTA.
  • Services Service list, who it is for, process, FAQ, contact CTA.
  • Blog / Resources Featured article, filter chips, card grid.
  • Pricing 3 tiers, what’s included, comparison notes, CTA.
  • Contact Short form, email, map or hours, trust line.
