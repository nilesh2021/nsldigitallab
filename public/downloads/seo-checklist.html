Technical SEO Checklist

Use this before an SEO campaign or site launch. Tick items as you verify them in Search Console, PageSpeed Insights, and your CMS.

Crawlability & indexation

  • robots.txt allows important pages Block only admin, search, and duplicate parameter URLs.
  • XML sitemap is submitted Includes canonical URLs only. No 404s, redirects, or noindex pages.
  • Canonical tags are correct One preferred URL per page. HTTPS, trailing-slash, and www rules are consistent.
  • No accidental noindex Check meta robots and HTTP headers on live pages.

Speed, mobile & security

  • HTTPS everywhere HTTP redirects to HTTPS. Mixed-content warnings are gone.
  • Core Web Vitals are acceptable Compress images, lazy-load below-the-fold media, and reduce unused JS.
  • Mobile-first layout works Tap targets, readable type, and no horizontal scroll on a 375px screen.

On-page & structured data

  • Unique title and meta description Match search intent. Keep titles under ~60 characters.
  • One H1, logical heading order Headings describe the page, not just design labels.
  • Internal links to key pages No orphan pages. Descriptive anchors, not “click here”.
  • Schema where it helps Organization, Article, FAQ, Breadcrumb, or Service as relevant. Validate in Rich Results Test.

Monitoring

  • Search Console coverage is clean Fix 4xx/5xx, redirect chains, and excluded pages you expected to index.
  • Analytics is firing GA4 (or equivalent) records page views and key conversions.
