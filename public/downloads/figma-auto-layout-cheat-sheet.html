Figma Auto Layout Cheat Sheet

Auto Layout is the Figma skill junior designers are asked about most. Use this while you build cards, nav bars, and buttons.

What Auto Layout is

In one sentence

Auto Layout makes a frame arrange its children in a row or a column, with padding and gap, so the frame grows when content grows — the way real UI is built.

When to use it

Buttons with icons, cards, lists, nav bars, form stacks, and anything that should not overlap when the text gets longer.

Controls you will use every day

Control What it does
Direction Vertical for a card’s contents. Horizontal for a button + icon or a nav row.
Gap Space between children. Prefer gap over empty spacer frames.
Padding Inner space from the edge. Keep it even unless you have a reason.
Hug Shrink to fit the content. Typical for buttons.
Fill Stretch to the parent. Typical for a title in a full-width card.
Absolute position Escape Auto Layout for a badge on a corner. Use rarely.

Shortcuts

  • Shift + A Add Auto Layout to the selected frame or wrap a selection.
  • Shift + Alt / Option + A Remove Auto Layout (varies slightly by Figma version — check the right panel if this does not fire).

Build this first: a product card

  • Vertical Auto Layout on the card Image, title, price, button. Set padding 16 and gap 12.
  • Title set to fill container Lengthen the title. The card should grow, not overlap the price.
  • Button is its own Auto Layout Horizontal: icon + label, hug both ways, padding 12 / 16.
  • Turn the card into a component Then duplicate it. Changing padding on the main component should update instances.

Interview answer (say this)

“What is Auto Layout?”

Auto Layout lets me build frames that behave like real UI: items stack in a row or column, padding and gap stay consistent, and the frame grows when content changes. I use it on cards, buttons, and navigation so developers are not handed overlapping layers.
