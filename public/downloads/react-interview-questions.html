React Interview Questions for Freshers

Plain-language answers for junior frontend interviews. Explain the idea, then give a tiny example from a project you built.

Core React

What is React?

A JavaScript library for building user interfaces from small reusable pieces called components. When data changes, React updates the matching parts of the screen.

What is JSX?

A syntax that looks like HTML inside JavaScript. It describes what the UI should look like. You use className instead of class.

What is a component?

A function that returns UI. You write it once and reuse it, for example a Button or ProductCard.

Props vs state?

Props are data passed in from a parent. State is data the component owns and can change, usually with useState. Props down, events up.

Hooks and data

What does useState do?

It stores a value that can change, and asking React to re-render when you update it — for example a form field or a like count.

What does useEffect do?

It runs extra work after render: fetch data, subscribe, or sync with something outside React. The dependency array controls when it runs.

How do you render a list?

Map over an array and return elements. Give each item a stable key (usually an id), not the array index if the list can change order.

What is React Router used for?

Showing different pages in a single-page app, such as /learn and /resources, without a full browser reload.

Practical

How would you fetch API data?

useEffect with a fetch (or similar), store the result in state, and handle loading and error UI. Cancel or ignore stale responses if the component unmounts.

Controlled input?

The input value comes from state, and onChange updates that state. React is the source of truth for the field.

Walk me through a project

Name the problem, the components you split, where state lived, and one bug you fixed. Interviewers want thinking, not a feature dump.
